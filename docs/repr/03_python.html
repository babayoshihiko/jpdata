3. Lecture 03: Python in QGIS

3.1. ★☆☆ Follow Along:

Python is one of the most popular programming languages.

QGIS is integrated with Python.

If you already have QGIS installed on your PC, you do not need to install anything to start programming.

Let's start Python in QGIS.

From the menu, select:

Plugins --> Python Console

The Python Console appears at the bottom of the QGIS window.

You can type Python code directly into the console.

For example, let's create a point at the location of Bangkok.

Type:

from qgis.core import QgsPointXY

point = QgsPointXY(100.5018, 13.7563)

print(point)

Press Enter to run the code.

The numbers are the longitude and latitude of Bangkok.

The point has been created in Python, but it is not yet displayed on the map.

3.2. ★★☆ Try Yourself:

Try changing the coordinates to Taipei.

point = QgsPointXY(121.5654, 25.0330)

What happens when you run the code?

3.3. ★★★ Follow Along:

Now let's display the point on the QGIS map.

Writing longer programs directly in the console is inconvenient.

In the Python Console, click Show Editor.

The Editor appears above the Python Console.

Now enter the following code:

from qgis.core import *

layer = QgsVectorLayer(
    "Point?crs=EPSG:4326",
    "Bangkok",
    "memory"
)

point = QgsPointXY(100.5018, 13.7563)

feature = QgsFeature()
feature.setGeometry(QgsGeometry.fromPointXY(point))

layer.dataProvider().addFeature(feature)

QgsProject.instance().addMapLayer(layer)

Click the ▶ Run button.

A point appears on the QGIS map at Bangkok.

Now change the coordinates to Taipei and run the program again.

point = QgsPointXY(121.5654, 25.0330)

The point should appear at Taipei.

The basic workflow is:

Show Editor
     ↓
Write Python code
     ↓
▶ Run
     ↓
QGIS map
     ↓
See the point

3.4. Summary

Python can be used to create and display spatial data in QGIS.

In this exercise, we created a point from longitude and latitude.

The Python Console lets us run Python code directly.

The Editor is useful for writing longer programs.
