5. Lecture 05: Creating a Graticule

5.1. ★☆☆ Follow Along:

A graticule is a set of lines showing latitude and longitude on a map.

Let's create longitude lines using Python.

5.2. ★★☆ Try Yourself:

  1. First, create an empty line layer.

from qgis.core import *

layer = QgsVectorLayer(
    "LineString?crs=EPSG:4326",
    "Graticule",
    "memory"
)

for lon in range(-180, 181, 30):
    points = [QgsPointXY(lon, lat) for lat in range(-90, 91)]

    feat = QgsFeature()
    feat.setGeometry(QgsGeometry.fromPolylineXY(points))

    layer.dataProvider().addFeature(feat)

QgsProject.instance().addMapLayer(layer)

The important programming concept in this example is the for loop.

for lon in range(-180, 181, 30):

The for statement repeats the following operations for different values of lon.

The variable lon takes the following values:

-180, -150, -120, ... , 120, 150, 180

For each value, the program creates one longitude line.

Without a for loop, we would have to write the same operation many times.

The range() function generates a sequence of numbers. Here,

range(-180, 181, 30)

means that we start at -180, increase the value by 30, and stop before going beyond 180.

Now, let's create latitude lines.

Can you modify the program so that it creates horizontal lines instead of vertical lines?

Think about:

  • Which variable should change?

  • What should range() contain?

  • Which coordinate should remain constant?

Try Yourself:

for lat in range(-90, 91, 30):
    ...

Try changing 30 to 10. What happens to the number of lines?

In this exercise, you are not learning a completely new program. You are modifying an existing program by changing the variable and the coordinates.

This is an important way of thinking about programming: understand a pattern, then adapt it to a new problem.
