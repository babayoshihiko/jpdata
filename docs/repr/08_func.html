8. Lecture 08: Using Functions

8.1. ★☆☆ Follow Along:

In the previous lecture, we used if to select particular cities from the data.

Now, let's make our GIS processing reusable.

A function is a block of code that performs a particular task.

The basic structure is:

def function_name():

    do_something()

For example:

def say_hello():

    print("Hello")

say_hello()

The code inside the function is executed when we call the function.

Functions are useful because we can perform the same operation many times without writing the same code again.

8.2. ★★☆ Follow Along:

Let's use a function to create a point from longitude and latitude.

First, define a function called create_point.

from qgis.core import *

def create_point(lon, lat):

    point = QgsPointXY(lon, lat)

    return point

The function receives two values:

  • lon: longitude

  • lat: latitude

It returns a QgsPointXY object.

We can now use the function to create a point.

point = create_point(100.5018, 13.7563)

print(point)

The important point is that the coordinate-processing operation is now represented as a function.

We can call the same function with another city.

point = create_point(121.5654, 25.0330)

print(point)

The function itself does not change.

Only the input values change.

8.3. ★★☆ Follow Along:

Now, let's use the function to display several cities on a QGIS map.

First, read the CSV file from the previous lecture.

import csv

cities = []

with open("data/cities.csv", encoding="utf-8") as f:

    reader = csv.DictReader(f)

    for row in reader:

        cities.append(row)

Next, define a function that creates a QGIS feature from a city.

def create_city_feature(city):

    lon = float(city["lon"])

    lat = float(city["lat"])

    point = create_point(lon, lat)

    feature = QgsFeature()

    feature.setGeometry(QgsGeometry.fromPointXY(point))

    return feature

Now, create a point layer.

layer = QgsVectorLayer(

    "Point?crs=EPSG:4326",

    "Cities",

    "memory"

)

Finally, use the function for each city.

for city in cities:

    feature = create_city_feature(city)

    layer.dataProvider().addFeature(feature)

QgsProject.instance().addMapLayer(layer)

The cities are now displayed on the QGIS map.

The workflow is:

CSV data

     ↓

city dictionary

     ↓

create_city_feature()

     ↓

QGIS feature

     ↓

map

A function allows us to describe a GIS operation as a reusable unit.

8.4. ★★★ Try Yourself:

Modify the create_city_feature() function so that it uses another pair of fields.

For example, suppose the CSV contains:

name,longitude,latitude

Bangkok,100.5018,13.7563

Singapore,103.8198,1.3521

Change the function so that it uses longitude and latitude instead of lon and lat.

Then display the cities on the QGIS map.

The same idea can later be applied to GTFS data.

For example, a GTFS stops.txt file contains stop names and coordinates.

A function can be used to convert each stop into a QGIS feature.

This allows us to move from:

CSV

     ↓

Python data

     ↓

function

     ↓

spatial feature

     ↓

map
