2. Lecture 02: jpData, Symbols and Other Visual Techniques

2.1. ★☆☆ Follow Along:

In this lecture, we will use jpdata to load spatial data of Japan into QGIS.

The jpdata plugin allows us to download and add various kinds of Japanese geospatial data to QGIS.

Install the jpdata plugin from the QGIS Plugin Manager.

After installing the plugin, select:

Plugins
    ↓
jpdata
    ↓
Add Japan Data

You can also access the same function from:

Layer
    ↓
Add Layer
    ↓
Add Japan Data

Let's load some data for Japan.

For example, select a dataset from National Land Numerical Information and download it.

After adding the data to QGIS, the layer will appear in the Layers panel.

Zoom to the layer.

We now have spatial data that we can represent on a map.

The geometry tells us where something is.

The attributes tell us what it is or how much there is.

A map combines these two kinds of information.

2.2. ★★☆ Follow Along:

Now, let's change how the data is represented.

Open the Layer Styling panel.

The simplest way to represent a layer is Single Symbol.

All features are displayed using the same symbol.

Try changing:

  • the colour

  • the size

  • the line width

  • the fill

  • the transparency

The data itself has not changed.

Only its visual representation has changed.

This is called symbology.

For example, a polygon layer can be represented as:

data
  ↓
geometry + attributes
  ↓
symbol
  ↓
map

The same data can therefore produce very different maps.

A good map does not simply display data.

It makes important information visible.

2.3. ★★☆ Follow Along:

Next, let's use an attribute to change the appearance of the map.

Open Layer Styling and select Categorized.

Choose an appropriate attribute field.

QGIS will assign different symbols or colours to different categories.

For example, if the data contains different types of facilities, we can represent them using different symbols:

Hospital       ●
School         ■
Station        ▲

The geometry of each feature is unchanged.

Only the visual representation is different.

This allows us to distinguish different kinds of spatial features quickly.

We can also use numerical attributes.

Select Graduated in the Layer Styling panel.

Choose a numerical attribute.

QGIS will divide the values into classes and use different symbols or colours.

For example:

small value     light
medium value    medium
large value     dark

This creates a visual relationship between an attribute and its representation.

attribute value

      ↓

colour / size

      ↓

visual pattern

2.4. ★★★ Try Yourself:

Choose another dataset using jpdata.

Change its symbology so that an important characteristic of the data becomes easy to see.

Try at least two different representations.

For example:

  • categorized symbols

  • graduated symbols

  • colour

  • size

  • transparency

  • labels

Compare the results.

Ask yourself:

Which representation makes the spatial pattern easiest to understand?

The purpose of spatial information representation is not simply to display data.

It is to choose an appropriate visual representation for the information we want to communicate.

In the next lectures, we will begin to create these spatial representations programmatically using Python in QGIS.
