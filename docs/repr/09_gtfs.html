9. Lecture 09: GTFS Animation

9.1. ★☆☆ Follow Along:

In the previous lectures, we learned how spatial information can be represented using points, lines, symbols, and other visual techniques.

We also learned how Python can be used to create and manipulate spatial information.

In this lecture, we will combine these ideas with GTFS.

GTFS stands for General Transit Feed Specification.

GTFS provides a standard way to represent public transportation information, such as:

  • stops

  • routes

  • trips

  • stop times

A GTFS dataset can therefore be used to represent not only where bus stops are, but also when vehicles move between them.

This makes it possible to create an animation of public transportation.

Watch the following example.

What you are seeing is a spatio-temporal representation of public transportation.

The position of a vehicle changes over time.

Therefore, the information can be represented as:

location

   +

time

   ↓

movement

   ↓

animation

9.2. ★★☆ Follow Along:

Let's think about what is represented in a GTFS animation.

A bus stop has a location.

This can be represented by a point:

stop

  ●

A route can be represented by a line:

●────●────●────●

A timetable tells us when a vehicle arrives at each stop.

stop A       08:00

stop B       08:05

stop C       08:12

stop D       08:20

When these pieces of information are combined, we can represent the movement of a vehicle.

stops

  ↓

routes

  ↓

stop times

  ↓

vehicle movement

  ↓

animation

The important point is that GTFS is not simply a map dataset.

It contains both spatial information and temporal information.

9.3. ★★★ Try Yourself:

Think about what information is needed to create a transportation animation.

For example:

  • Where is the bus stop?

  • Which route does the bus use?

  • Which trip does the vehicle belong to?

  • When does the vehicle arrive at each stop?

  • How can the vehicle position be calculated between stops?

Try to identify the corresponding information in a GTFS dataset.

The basic structure is:

stops.txt
    ↓
Where are the stops?

routes.txt
    ↓
Which routes exist?

trips.txt
    ↓
Which trips operate?

stop_times.txt
    ↓
When does each trip visit each stop?

These files can be combined to reconstruct the movement of public transportation.

This is an example of how spatial information can be represented dynamically.

In the next lecture, we will combine list, for, if, and functions to process spatial data in Python.
