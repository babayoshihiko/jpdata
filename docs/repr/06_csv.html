6. Lecture 06: Reading CSV Data in QGIS

6.1. ★☆☆ Follow Along:

So far, we have created spatial data directly in Python.

But real GIS data are usually stored in files.

One of the simplest formats for tabular data is CSV.

CSV stands for Comma-Separated Values.

For example, suppose we have a file called cities.csv:

city,lon,lat
Bangkok,100.5018,13.7563
Singapore,103.8198,1.3521
Kuala Lumpur,101.6869,3.1390
Jakarta,106.8456,-6.2088
Taipei,121.5654,25.0330

Each row represents one city.

The first row contains the column names.

Let's read this file using Python.

import csv

with open("cities.csv", encoding="utf-8") as f:
    reader = csv.DictReader(f)

    for row in reader:
        print(row)

Each row is a dictionary.

For example:

{'city': 'Bangkok', 'lon': '100.5018', 'lat': '13.7563'}

We can access individual values using their column names.

print(row["city"])
print(row["lon"])
print(row["lat"])

This is useful because we can work with the data using meaningful names such as city, lon, and lat.

6.2. ★★☆ Try Yourself:

Change the program so that it prints only the city name.

print(row["city"])

Try changing "city" to "lon" or "lat".

What happens?

Now let's store all the rows in a list.

cities = []

with open("cities.csv", encoding="utf-8") as f:
    reader = csv.DictReader(f)

    for row in reader:
        cities.append(row)

The variable cities is now a list containing dictionaries.

We can check the first item:

print(cities[0])

The result is:

{'city': 'Bangkok', 'lon': '100.5018', 'lat': '13.7563'}

We can also access the city name:

print(cities[0]["city"])

The important idea is:

CSV
 ↓
dictionary
 ↓
list of dictionaries

This is a common way to handle tabular data in Python.

6.3. ★★★ Follow Along:

Now let's put the cities on the QGIS map.

First, create an empty point layer.

from qgis.core import *

layer = QgsVectorLayer(
    "Point?crs=EPSG:4326",
    "Cities",
    "memory"
)

Next, read the CSV file.

import csv

cities = []

with open("cities.csv", encoding="utf-8") as f:
    reader = csv.DictReader(f)

    for row in reader:
        cities.append(row)

Now we can use the for loop to create a point for each city.

for city in cities:

    lon = float(city["lon"])
    lat = float(city["lat"])

    point = QgsPointXY(lon, lat)

    feature = QgsFeature()
    feature.setGeometry(
        QgsGeometry.fromPointXY(point)
    )

    layer.dataProvider().addFeature(feature)

Finally, add the layer to QGIS.

QgsProject.instance().addMapLayer(layer)

Click ▶ Run.

The five cities should appear on the QGIS map.

The complete program is:

from qgis.core import *
import csv

layer = QgsVectorLayer(
    "Point?crs=EPSG:4326",
    "Cities",
    "memory"
)

cities = []

with open("cities.csv", encoding="utf-8") as f:
    reader = csv.DictReader(f)

    for row in reader:
        cities.append(row)

for city in cities:

    lon = float(city["lon"])
    lat = float(city["lat"])

    point = QgsPointXY(lon, lat)

    feature = QgsFeature()
    feature.setGeometry(
        QgsGeometry.fromPointXY(point)
    )

    layer.dataProvider().addFeature(feature)

QgsProject.instance().addMapLayer(layer)

Now we have connected a file containing tabular data to a map.

The workflow is:

CSV
 ↓
Python
 ↓
list / dictionary
 ↓
coordinates
 ↓
QGIS map

This is also the basic idea behind working with many real-world GIS datasets.

For example, GTFS contains files such as stops.txt. The file contains information such as stop names and coordinates.

The same basic approach can be used to read those data and display bus stops on a map.

6.4. Summary

A CSV file stores tabular data.

Python can read CSV data using the csv module.

csv.DictReader converts each row into a dictionary.

We can store multiple rows in a list.

We can then use a for loop to convert the data into spatial features and display them in QGIS.

The important workflow is:

CSV → list/dictionary → spatial data → QGIS
