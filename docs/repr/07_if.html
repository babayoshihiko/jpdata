7. Lecture 07: Selecting Data with if

7.1. ★☆☆ Follow Along:

In the previous lecture, we read a CSV file and displayed the cities on a map.

Now, let's select particular cities from the data.

In GIS, we often want to answer questions such as:

  • Which cities are north of the equator?

  • Which bus stops are within a certain area?

  • Which places have a particular attribute?

Python's ``if`` statement allows us to make these decisions.

The basic structure is:

if condition:
    do_something()

The indented code is executed only when the condition is True.

For example:

lat = 13.7563

if lat > 0:
    print("Northern Hemisphere")

Here, lat > 0 is the condition.

Because Bangkok is north of the equator, the condition is True.

7.2. ★★☆ Follow Along:

Let's apply if to the city data from the previous lecture.

First, read the CSV file.

import csv

cities = []

with open("data/cities.csv", encoding="utf-8") as f:
    reader = csv.DictReader(f)

    for row in reader:
        cities.append(row)

Now, let's look at each city.

We will display only cities north of the equator.

for city in cities:

    lat = float(city["lat"])

    if lat > 0:
        print(city["city"])

The result is:

Bangkok
Singapore
Kuala Lumpur
Taipei

Jakarta is not included because its latitude is south of the equator.

The important point is that the for loop processes every city, while the if statement decides which cities should be processed further.
